Connect Google

Approved project briefs go to Google Docs in your FDE Drive folder. Agreed delivery dates go to a dedicated FDE Deliveries calendar.

  1. In your Google Cloud project, enable the Drive, Docs and Calendar APIs. Configure the consent screen and create a Desktop app OAuth client.
  2. Download the client JSON outside this repository, then run setup-google.cmd in the repository root. Enter the file path in that terminal.
  3. Open the sign-in URL shown by setup and consent with the account you want to use.
  4. Return to the terminal and confirm creation of your FDE folder and FDE Deliveries calendar.
  5. Configure the extraction runtime described in docs/CONNECTED.md. Restart with npm run start:connected, enter that document's fictional transcript, permit extraction, inspect the evidence and approve the brief. Sending it to Google is a separate action.

Credentials are encrypted for your Windows account. Keep downloaded client files and tokens private. Full instructions and recovery steps are in docs/CONNECTED.md.

Setup creates private destinations. Sharing with a company or client is a separate owner action.
